# AegisVPN Professional Website

Premium responsive VPN marketing website built with Next.js App Router.

## Run locally
1. `npm install`
2. `npm run dev`
3. Open `http://localhost:3000`

## Deploy
Import this GitHub repository into Vercel. Vercel should auto-detect Next.js and use the standard `next build` command.

## Before going live
Replace the placeholder brand `AegisVPN`, pricing, support/signup destination, legal pages, server counts, and any security/privacy claims with your real product details.
